# Observability Dashboard

Standalone repository split from `agentic-commerce-platform`.

## What This Demonstrates

Structured logs, trace IDs, metrics endpoint, event timeline, sample dashboard config, and React observability UI.

This is a demo/training project. It uses mock grocery data only. It does not use real Kroger APIs, real payment APIs, real customer data, or secrets.

## Setup

```bash
make setup
```

## Run

```bash
make run
```

## Verify

```bash
make test
```
